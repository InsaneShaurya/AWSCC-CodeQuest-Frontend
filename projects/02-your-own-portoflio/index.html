Unit I

Computer, hardware & software

Introduction · classification · I/O · software

A computer is an electronic device that accepts raw data as input, processes it according to stored instructions, and produces meaningful information as output. Modern computers do far more than calculate: they communicate, create, analyse, and automate.

01 / INPUTRaw data and instructions enter the system.
02 / PROCESSThe CPU performs calculations and logical operations.
03 / OUTPUTUseful information is presented to the user.

1.1.1Characteristics of a computer

Performance

Speed & accuracy

Executes millions or billions of instructions per second. Correct input and instructions produce correct results—this is the GIGO principle.

Consistency

Diligence & reliability

Performs repetitive work without fatigue and gives consistent results for the same input.

Capability

Storage & versatility

Stores large volumes of data and can be used for accounting, design, research, gaming, and more.

Operation

Automation

Once a program is started, the computer follows its instructions until it completes or an error occurs.

1.1.2Limitations

Computers follow instructions; they do not possess human judgement.They have no inherent intelligence, feelings, or intuition. They depend on correct programs and data, require power and maintenance, and cannot learn without suitable algorithms or models.

1.2Hardware: input & output

Input devices
Keyboard: enters text, numbers and commands.   Mouse: selects on-screen objects.   Scanner: digitises printed documents.   MICR: reads magnetic-ink characters on cheques.   OMR: detects marked positions on answer sheets.   Bar-code reader: identifies products from printed codes.   Joystick / light pen: control or select on screen.
Output devices
VDU / monitor: displays soft-copy text, images and video.   Printer: produces hard copy; common types include dot-matrix, inkjet and laser.   Plotter: makes large, precise engineering drawings.   Speaker: converts signals to sound.

Unit II

Memory & storage

Primary · secondary · cache · registers

Memory stores data and instructions either temporarily or permanently. Primary memory is directly accessible to the CPU during program execution; secondary memory keeps information for long-term use.

2.1Primary memory

Volatile

RAM — Random Access Memory

Fast working memory for the OS, active programs, and data currently in use. Its contents are lost when power is removed. RAM supports direct access and read/write operations.

Non-volatile

ROM — Read-Only Memory

Stores persistent firmware and boot-up instructions. ROM retains information when power is off; modern forms may be electrically rewritten.

2.2RAM and ROM at a glance

RAMROM
Temporary and volatilePermanent and non-volatile
High-speed read/write memoryPrimarily read-only firmware storage
Used by active instructions and applicationsUsed in bootstrapping, BIOS, and microcontrollers
Includes SRAM and DRAM (SDRAM, DDR)Includes MROM, PROM, EPROM, EEPROM, Flash ROM

2.3Memory close to the CPU

Cache memory
A small, very fast volatile memory placed between the CPU and RAM. It keeps frequently used data and instructions close to the processor, reducing access latency and improving performance.
Register memory
The smallest and fastest storage inside the CPU. Key registers include the Program Counter (PC), Instruction Register (IR), Memory Address Register (MAR), and Memory Data Register (MDR).
Virtual memory
A technique that uses part of secondary storage to extend apparent main memory. It lets large programs run, but disk access is slower than RAM and may reduce performance.

2.4Secondary memory

Magnetic storage

Hard disk drives and magnetic tape. Tape is low-cost and high-capacity but supports sequential access only.

Optical storage

CD-ROM, CD-R, CD-RW, DVD and Blu-ray use lasers for reading and writing data.

Flash storage

SSDs, USB drives and memory cards use non-volatile NAND/NOR flash and have no moving mechanical parts.

Cloud & hybrid storage

Services such as Drive, OneDrive and S3 provide remote storage; hybrid drives combine HDD capacity with SSD speed.

Computer languages

Machine · assembly · high level

Programming languages are the methods used to instruct a computer to perform tasks. They have progressed from hardware-specific binary instructions to human-friendly, machine-independent languages.

3.1Language levels

Lowest level

Machine language

Binary 1s and 0s understood directly by a particular computer. It is fast but machine-dependent, difficult to write, debug, and modify. An instruction has an opcode and operand.

Symbolic level

Assembly language

Uses mnemonic codes such as ADD instead of binary codes and symbolic addresses. An assembler translates it to machine language. It remains hardware-dependent.

Human-friendly

High-level language

Uses English-like words and familiar symbols. It is easier to learn, document, maintain, and transport, although it offers less direct hardware control.

Translation

Compiler & interpreter

A compiler translates an entire source program into object code. An interpreter translates and immediately executes one statement at a time.
